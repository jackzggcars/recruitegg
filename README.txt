Build:  install JDK 21 + Gradle (or copy the gradle wrapper from the NeoForge MDK), then run:
        gradle build
Jar:    build/libs/recruitegg-1.0.0.jar  -> put in the server's mods folder
Needs:  NeoForge 1.21.1 + the Recruits mod on the server.
Command: /recruiteggs  (64 eggs, 5 hour cooldown per player, survives restarts)
